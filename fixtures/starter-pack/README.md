# Starter pack: the Rivera household

Everything Jordan Rivera has on hand about the family's helpers, in the form it actually exists.
It's now early October, and September's bills just came in.

| File | What it is |
|---|---|
| `01-household-notes.txt` | Notes Jordan typed from memory |
| `02-priya-rates.png` | Screenshot: the text thread where Jordan and Priya (babysitter) agreed on rates, June |
| `03-lupe-rates.png` | Screenshot: the first text thread with Lupe (cleaner), January |
| `04-lupe-rate-change.txt` | A later thread with Lupe, copied out of Jordan's phone, late August |
| `05-theo-rates.png` | Screenshot: a text from Theo (dog walker), late August |
| `06-priya-september-bill.txt` | Priya's September bill, sent by text |
| `07-lupe-september-bill.png` | Screenshot: Lupe's September bill |
| `08-theo-september-bill.txt` | Theo's September bill, sent by email |

The data is realistic: messy, sometimes contradictory, sometimes wrong.

Your app should start empty. Jordan gets these into it through your UI, the same way a real user would.
